# F006：空教室位置示意图

需求：依据用户在 KIT DevOps 发送的综合楼现场平面图，参考图书馆图片加简洁摘要的展示方式，避免默认列出几十间教室；保留当前时间推荐、指定大节、全天和其他机器人功能，并完成真实群聊验收。

基线：908bfbf，及本轮冻结的线上源文件。复用已确认的资料读取/命令调度、私聊及群聊展示、原生保存重载三个测试边界。

- 图纸截图已核对二、三、五、六号楼楼层与房号；先按金明对应综合楼与教务返回的楼号、房号核对后展示。仅画截图能确认的位置，非比例图；不将楼栋布局套给其他校区或楼栋。
- 默认一张示意图、一段简短摘要，最多列3个教室示例；无对应图纸或图片失败时也不恢复长列表。完整清单经“教室清单”按需查看，复用原有文字分页，按机器人/聊天/提问者隔离且保留时效。
- 单大节绿色只表示学校本次结果明确返回且时效有效的课程未占用教室；其他教室标为未核验，不能依据缺席房间推断占用、关闭或现场可用。
- 全天图若展示各大节，用独立的五个状态点，不把单节未占用说成全天空闲；保留每节时效和来源。未核实作息不换算24小时，不改变原有查询条件。
- 地点冲突、缺少房号、过期或不完整结果不显示绿色可用状态。未匹配到图纸的房间在摘要提示，不虚构位置。
- 图片发送失败只降级一次简短文字，不重发结果不确定的图片。使用原生 QQ 消息锚点发送，必须实际验证群图片链路。
- 用户已要求直接依据截图，不再保存原图；发布包仅包含结构化位置数据、渲染代码及许可允许的字体子集，不包含群聊天原图。

验收：真实 CLI/卡片路径输出 PNG 与简短文字；核对已知房间相对位置、绿色/未核验语义、全天五节、跨人/群/机器人、完整清单与下一页、图片失败降级；解包检查新增字体资源；原生热重载后核对原配置、流水线、知识库及机器人，再到 KIT DevOps 实测。
