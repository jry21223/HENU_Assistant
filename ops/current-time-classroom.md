# F005：按当前时间推荐空教室

用户要求：默认按当前时间推荐，沿用已知校区和楼栋，减少重复追问；上线后在 KIT DevOps 实测，保留原功能。

评审基线：cd6aabb，以及本轮冻结的线上源文件。测试沿用已确认的读取与命令调度、私聊及群聊展示边界；原生保存及重载后检查既有配置。

- “找自习室”“空教室查询”“现在呢”及未指定时间的完整地点问句，默认按北京时间查询当前大节。课间选今天下一大节，晚间课程结束后选明天第一大节；明确显示日期、24 小时时段及当前/下一时段，不声称教学时间以外全部空闲。
- 只有明伦、金明且保存作息与已核实作息一致时自动换算。其他校区保留指定大节及全天入口，不套用开封作息。
- 同一机器人、同一聊天、同一提问者沿用最近一次成功、无歧义、校区楼栋一致的查询地点。仅保存公共地点，不保存聊天正文；保留 24 小时，重载后仍可使用。未核验、失败、不完整或冲突的结果不更新地点。
- 明确的新校区、楼栋、手动大节、全天及日期条件优先；切换校区清除旧楼栋。自动时段每次重新计算，不冻结在上一次选择楼栋时的时段。
- 自动查询只使用已有教务会话，不自动认证。保留缓存时效、课程占用和现场开放限制说明。
- 跨人、跨群、跨机器人隔离。原有单大节、全天、帮助、课表、图书馆、新旧知识库及热重载保持可用。

验收：公开消息入口与真实 CLI/卡片、原生 Storage/查询代理替身验证上述行为；线上只替换本轮源文件并执行原生重载，核对配置及资源不变；KIT DevOps 实聊地点沿用、当前时间推荐、显式覆盖与原功能回归。
