# 已保存教务账号的私聊验证

本人私聊发送“验证登录”，通过已隔离的 LangBot Storage 读取现有账号，调用现有账号验证和本人主体检查；不把凭据发送给模型，不变更绑定主体。群聊只提示转私聊。

执行前写入原生 Storage 的 pending 预留，处理中或未知结果禁止重复提交。每个保存账号有60秒冷却和24小时最多3次失败预算；旧版线上 save_account 的共享学号预算继续生效。未知响应和 Storage 保存失败保留阻断状态，需人工核对后处理。验证码、锁定和错误密码不尝试绕过或自动重新认证。

线上4.10.11存在独立兼容修改。发布时冻结当前源码并只合并审核过的函数差异，不用仓库全量覆盖。login-status.patch 仅修正旧版无历史记录默认 unknown 的展示；真实 unknown 保留。新入口只恢复当前调用者的会话，全天查询仍只使用有效已有会话，不在群内自动提交密码。

回归边界：现有账号读取和命令调度、本人私聊与目标群展示；学校HTTP和 LangBot Storage 是测试外部适配器。代码通过与真实学校登录、QQ卡片验收分别记录。
