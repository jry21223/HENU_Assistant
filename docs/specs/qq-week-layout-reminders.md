# QQ 课表版面与提醒

用户要求：周课表按天清楚分组、减少分页；每次上课前15分钟提醒，连堂课一次，按已有教学周筛选。

版面：按周一至周日排序，各天独立标题与日期，课程突出节次/名称/地点；已筛周的周视图不重复每课周次。正常11项课程一张卡片；超出字节预算仍安全分页，续块保留星期标题；未知周次不可断言无课。完整学期/日课表保持现有语义。

提醒：核对官方消息能力后实现，不能把被动回复窗口当作全天主动推送，不能声明未送达的提醒已开启。官方主仓库发送消息文档明确自2025-04-21停止主动推送。系统日历仅作备选说明，未实现，也未改变用户通知渠道。当前机器人实际主动消息已验证送达，采用QQ方案。

实际探测更新：当前HENU-Bot qqofficial主动发送接口返回HTTP200并给出消息ID，与旧文档有出入。继续实现QQ提醒，持久化订阅、课前15分钟、按当前教学周、已保存节次钟点，未配置不猜时间；去重记录发送前写入，重启/超时不重发，关闭取消待发测试。提供45秒后台测试，与真实课程提醒明确区分。最终必须QQ客户端核对实际收到。

宿主边界：当前LangBot QQOfficialAdapter.send_message为空实现。必须接入已有C2C实际发送器并要求回执ID；仅插件调度完成或SDK空调用返回不算送达。ops/qq_active_transport.py为精确方法覆盖源，宿主其他源码hash保持一致，并保存可重建运行镜像及旧镜像回滚点。
