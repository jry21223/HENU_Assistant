# 教室目录与课表覆盖

用户要求继续定位2306、2406、5301、5302、6305、6405缺课表的原因，将确认的映射接入线上；不能确认的保持未核验，并实测展示图片。

运行时刷新教室课表时，同时读取同一校区和楼栋的学校完整教室目录，将精确房间名称、学校ID、类型与查询结果一同保存。目录存在不等于有课表覆盖；不得将目录中但课表没有返回的教室加入空闲/占用集合。保留原来的图片风格、坐标、账号绑定和其他热修。

卡片及图片应明确列出已经匹配目录但课表未覆盖的房号。目录读取失败、返回其他楼栋、旧缓存缺目录元数据时，不声称已经匹配。全天五个大节独立判断，目录信息不得覆盖课表时效校验。

验证沿用已授权的公开查询结果、卡片和图片边界：学校目录映射可随新鲜缓存返回；目录有但课表无的房间仍为未核验；有课/无课的已有房间状态不变；过期、失败、不同校区/楼栋数据不能确认映射。真实学校接口只读，真实QQ验收单独记录。

发布仅LangBot分支；共享查询新增的是可选目录元数据，MCP和agent-skill分支本轮不发布，记录差异。任何单房间对照请求若忽略范围返回整校区数据，应判无效，不据此修改课程状态。
