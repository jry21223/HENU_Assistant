# 图书馆座位查询仅回复图片

用户在真实 QQ 私聊查询第一自习室，已收到座位图片，却又收到包含约一百个座位的文字卡片。用户确认成功查询只保留图片，并要求真实验收。

- 对已生成并发送成功的图书馆座位图，仅发送该图片，不追加同一结果的文字清单或进度消息；单时间点查询也适用。
- 纯座位图片结果不追加模型的补充说明，避免模型看不到已生成图片时输出“无法生成图片”等矛盾描述；混合查询及图片失败的文字回退仍保留说明。
- 自然语言、公开 CLI 展示和选座菜单保持一致。保留后续选择座位、预约预览及独立确认的能力。
- 图片缺失或发送失败仍返回既有文字回退；发送状态未知时不自动重发图片。
- 同时请求的课表、说明、确认预览和提交回执不受影响；空教室图片展示不改变。
- 纯图片结果清空旧文字分页，不能通过翻页重新取出旧结果。
- 延用已约定的公开 CLI / QQ 展示入口进行回归；真实验收核对 QQ 实际收到的图片和消息数量。不得通过测试创建预约或交卷。
- 在线发布采用当前兼容树上的最小补丁，保留现有运行时、认证、课堂地图、图书馆和确认实现。
