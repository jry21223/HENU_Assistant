# 空位提醒排版迭代

用户要求实际QQ验收并迭代排版样式，沿用此前QQ展示规范：结果在前、详情其次、操作最后；短句、分组、不展示内部编号；保留失败、未知、过期和确认事实。

真实QQ基线已观察：帮助把语法、例子和规则挤成一段，方括号转义可见；旧帮助的七层南14:00–16:00例子无法按学校整段时段设置；08:00–23:00设置成功后，状态卡堆出20个座位号，取消状态仍重复检查频率和运行规则。

- 帮助分别提供区域、单座两个可整段复制的例子，使用已实测完整时段；避免内部ID、可选参数括号、转义符和大段语法说明。
- 状态卡分开显示当前状态、区域、日期和使用时段、监控范围、最近检查。活跃时显示检查间隔和查看/取消入口；取消、到期、暂停状态不显示仍在运行的频率。
- 首次查询显示已确认空位数量，座位示例最多6个；未知状态不得变成0或沿用旧空位数。
- 新空位通知保留地点、完整时段、新增数量与最多6个座位号，清楚表明仍在监控；纯文本主动消息也能读懂。
- 各段单独转义学校字段，保留可信展示结构；操作提示与不确定发送事实不能因整段500字符截断而丢失。
- 不改变区域/单座范围、5/10分钟频率、去重、登录暂停、到期及取消机制。
- 公开消息/SDK与查座→通知仍为测试边界。验收覆盖QQ帮助、实际设置、状态、取消和清晰标注的测试通知；测试订阅最终清理，真实校园预约不提交。
