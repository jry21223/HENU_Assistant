# Kit 终身会员定时图书馆预约

用户已确认：仅允许当前 QQ 已绑定 Kit 且服务端核验为终身会员的用户使用。
创建计划和每次执行前重新鉴权；未绑定、非终身会员或鉴权异常均不执行。
用户先核对并在后续消息确认具体预约计划，偏好不是自动预约授权。
设置计划与定时执行是验收入口，覆盖鉴权拒绝、防重复提交。

首版提供指定日期的单次定时计划（可分别设置多天），明确执行时间、预约日期、区域、座位、起止时间。
不推断抢座开放时间；任务逾期不补执行；结果未知不自动重试。
仅 LangBot QQ 版本具备该权益与后台任务；MCP/Agent Skill 普通手动预约行为不变。

Kit 会员接口必须来自服务端的真实会员记录，不采用聊天自述、本地缓存或模型参数。
服务端会员契约核实前不宣称可以上线。

## 追加确认范围

用户补充学校 yzsfz 服务，并确认先启用状态和记录查询。
该服务对应现有河宝社区接口；增加确定性的私聊查询入口与帮助，
不增加办理请假、签到、查寝等写操作。旧的宽松 token 成功判定与
失败后的第二轮登录应收紧，不把未知响应当作有效登录。

## 会员所有者接口

采用独立凭据的 Account Portfolio `GET /api/v1/bot/membership-entitlement`，
先经 Core resolve 确定当前 QQ 的 active/verified 绑定主体，再以签名 actor UID
查询 lifetime boolean，响应 UID 必须一致。查询异常拒绝设置和执行。
每个用户和 Bot 最多一个活动计划，取消可释放尚未执行的计划。
