# 自定义日程

用户可在 HENU Bot 私聊里维护年级大会、班会、党员大会等个人安排，无需绑定校园账号。自然语言由现有 Agent 转为 `henu_cli` 的 `event` 命令；命令及“我的日程”“今天日程”“明天日程”“自定义日程”也支持直接处理。

## 行为

- `event help`：查看完整参数。
- `event add --title 班会 --start "2026-11-06 19:00" --location 综合楼2305`：保存日程，默认提前15分钟提醒。
- `--end "2026-11-06 20:00"`、`--note "带笔记本"` 可选；`--remind-minutes 30` 自定义提前分钟数，`off` 关闭、`0` 开始时提醒。
- `event list` 查看未来或仍在进行的日程；`--date YYYY-MM-DD` 查看指定日期（含当天已结束日程）；每页8项，使用 `--offset 8` 继续查看。
- `event update --id <本人日程编号> --start "2026-11-06 19:30"` 修改；若原结束时间不再晚于开始时间，须同时提供新结束时间。
- `event cancel --id <本人日程编号>` 取消并停止后续提醒；取消后不再出现在查询结果中。

全部时间为 Asia/Shanghai；不得猜测不完整日期、时间，不创建过去的日程。标题/地点各100字、备注500字；提醒0至10080分钟；每人每机器人最多100条未来日程。日程与教务课表分开保存，同一聊天身份在不同机器人中的日程也隔离。当前不提供群共享、循环日程或 QQ/微信消息自动收集。

## 持久化和投递

插件 Storage 的 `custom_events:v1` 按机器人和发送者的组合散列划分所有者，不接受工具提供目标用户。查询、修改、取消只能访问当前本人名下的编号。写失败不报告成功；读取失败或损坏不覆盖存量数据。保留历史日程与取消记录，不因新增或修改自动删除；同一次查询和相同命令用持久回执防重复，回执保留一天。

独立后台任务每30秒扫描；每条提醒发送前加锁重新核验并持久保存带唯一编号的 `unknown` 投递声明，网络发送期间不持锁，后续提醒尚未声明前可正常取消。发送回执重新读取存储，只更新同一声明，不覆盖期间的修改或改期。超时、进程退出或发送后回执保存失败均不自动重发。正常返回标记 `sent`，只表示接口受理，不能证明 QQ 实收。停机后恢复如会议尚未开始会补发提醒；开始后超过60秒不补发过期提醒。仅开始时间或提前提醒分钟数实际改变时重新布置提醒，重述相同时间、只改标题地点均不会重复发送。进行中的日程可修改标题、地点、备注或结束时间；改变开始时间仍须选择未来时间。关闭提醒或取消不发送未声明的提醒，已声明并正在投递的消息无法撤回。

## 发布与验收

目标分支 `langbot-plugin`。本次变更包含新增模块、主入口初始化、当前主监听器、统一工具、CLI帮助及卡片标题；不升级依赖，不迁移教务凭据，不更改独立 MCP/Agent Skill 分支。

生产存在既有覆盖层，不能以仓库整包覆盖。部署前备份当前受影响文件、记录哈希，按差异移植；保持用户数据及其他插件不变。检查既有主动私聊发送通道仍有效，重启插件后核验初始化和后台任务。用本人授权的测试日程验证保存、改期、取消、重启保留和 QQ 实收；没有明确发送授权不向任何 QQ 用户发送测试消息，无真实投递回执不得声称已送达。生产部署与 QQ 实收状态以单独验收记录为准，构建与合并不能替代上线。

自定义日程仅在 LangBot 分支运行。教室身份分离修复同样先交付 LangBot；独立 MCP 与 Agent Skill 分支的共享包副本尚未同步，不属于本次机器人发布。
