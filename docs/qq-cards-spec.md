# QQ 功能卡片规格

基线：`origin/langbot-plugin` 的 `1f13d98`。只改 LangBot 交付分支，不改共享校园业务行为。

- 所有现有 CLI 路由，以及 KIT 绑定、美食、敏感命令和确认回执，使用统一卡片。
- 结果状态在前；时间、位置、课程、座位/房间、记录与下一步清晰展示。帮助、未绑定、空结果、错误、过期和长内容也有卡片。
- 群聊只展示公开查询与帮助；个人账号、课表、预约记录、河宝、选课、雨课堂和美食草稿/本人投稿使用私聊。不得把个人原始工具输出交给群聊模型。
- 每次只回复一页，分页绑定机器人、发送者和会话；十分钟过期。最多缓存 20 页，并明确超出范围需重新筛选。保持原始业务数据不变。
- 使用官方 `markdown.content`；不依赖模板审批，不发送 keyboard，不新增按钮/回调或申请。
- SDK 用可稳定序列化的 Plain 传递卡片。提供独立的宿主适配补丁，把专属卡片前缀转为 msg_type=2；频道和未适配宿主保持可读文字。明确 HTTP 拒绝后回退文字，网络结果不明不重复发送。
- 不上传图片；不生产部署，不发送真实 QQ 消息。课表定时推送不存在，停用的 PDF/PPT/试卷文件推送不新增。

验证边界：CLI Tool 返回与回复事件、直接回复 SDK 序列化、分页会话/过期、宿主 HTTP 出站载荷和拒绝回退。仅运行相关测试与包装检查；独立 Standards/Spec 评审后创建 draft PR。
