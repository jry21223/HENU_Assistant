# 雨课堂测验与考试身份修复

基线：4673d255d3cd4d50a82d94e77b7087cc238b3a69。

用户授权：先修复测验/考试混用和试卷关联校验，再验收“数字逻辑第2次测试”的自动答题与答案保存，暂不交卷。

## 行为约定

- 官方活动 `type=4` 为测验（quiz），`type=5` 为考试（exam）；缺失、未知或错误类型不得猜成考试。
- 活动身份由班级、类型和活动对应的资源编号共同限定；quiz 与 exam 即使数字编号相同也不是同一活动。
- 查询结果取自已核验班级的官方活动列表，不得将 quiz 编号传给 exam 封面接口，也不得用未能关联的封面覆盖活动时间等信息。
- 如果响应显式声明了班级，则必须与请求班级一致；同一复合身份的重复记录、无效标识和结构错误应整次拒绝，不展示部分成功。
- 现有公共 CLI `yuketang exam list --course ...` 保留；结果明确区分测验和考试。历史 `exams` 数组名称保留，只有真正的考试才提供 `exam_id`，测验使用 `quiz_id`。
- 查询与验证不开始作答、不获取试题、不写配置、不推送执行任务、不交卷。
- 真实自动答题及仅保存答案取决于朋友维护的执行端。未经核验的 quiz 执行能力或不明确的保存/交卷接口不得作为验收通过。

## 测试接缝

沿用此前确认的公共 HenuCli、实际服务与外部 HTTP 边界；仅替换外部响应，使用合成账号与数据。先覆盖真实观察到的 quiz/exam 编号碰撞及错误封面，再逐项覆盖类型、班级、重复身份与现有考试查询。完整回归和规范/需求独立审查在提交前完成。

## 交付边界

修复客户端和回归测试不代表远端执行端已部署，也不代表真实答案已保存。QQ 消息、执行端、官方答案回读与正式交卷分别报告；本轮正式交卷不在授权范围。
