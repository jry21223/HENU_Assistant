# 雨课堂考试插件上线完善

基线：9288cbc01a1ea5ba2acb262b1fe08089274926a9。用户已授权按 Matt Pocock 工作流审查、修复并上线。工作区共享的 docs/agents 配置已完成，适用于本发布 checkout。

## 验证过的流程

登录与确认配置 → 唯一课程解析为班级白名单 → 启用监听 → 用户从官方入口开始考试 → 后台接管考试登录并保存答案 → 用户检查并正式交卷。真实验收为 40/40 已答、97.5/100、1 道错题、0 道未答；最终交卷由浏览器完成。后台使用常用身份，独立 CLI 测试身份已停用，不能称作独立身份的无人介入全自动闭环。

## 本次插件改动

1. 所有雨课堂 CLI 路由拒绝未知参数、重复参数（含连字符/下划线等价写法）、缺少值、意外位置参数及无参命令多余参数，错误不进入写配置/确认/桥推送。保留合法别名、带空格课程名、原禁用功能的明确提示；通用非雨课堂参数行为不变。
2. status 只在桥连接、配置 hash 一致、执行器已接入、心跳新鲜、身份注册与 enabled 一致时确认监听已运行/已停用；缺字段、心跳过期或注册不符明确无法确认。结果不暴露其他身份、凭据或远端原始响应。
3. 帮助、工具提示和 README 明确需要用户开始考试；后台接管可能使浏览器显示其他设备登录，不应在作答期间反复重登。答题保存不代表正式交卷；现有桥没有题级完成/交卷回执，不能用配置成功、心跳或预计耗时推断完成。不宣称无需人工的自动开始/自动交卷或保证满分。
4. 配置 mutation 保留真实用户确认、每用户隔离、先 Storage 后桥与离线停用/移除。存量账号不自动启用、重登或修改；线上较新 Storage/登录/预约补丁保留。

## 重复身份的责任边界

同一雨课堂账号在多个身份、多个部署或独立 CLI 下可能重复执行。A 的每 QQ 锁无法构成全局账号排他；现桥 API 没有权威账号租约接口。应由实际 B 服务基于已认证雨课堂账号和考试 ID 建立唯一执行归属，重复任务拒绝/复用，失效进程可恢复且不覆盖已提交试卷。待提供 B 源码及部署入口后在其真实实现与测试接缝修复；不通过删除其他用户、猜测身份或在 A 侧静默抢占来伪装已解决。
