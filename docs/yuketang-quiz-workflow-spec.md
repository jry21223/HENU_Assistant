# 雨课堂测验取题、默认保存与独立确认交卷

基线：ce86d2a（含活动身份修复）。用户要求将已真实验收的测验答题流程整合到代码，默认只保存答案，交卷时单独确认。

## Problem Statement

现有插件只能查询测验元数据、配置远端考试监听。已验证的 quiz 开始、取题、缓存保存、正式交卷和成绩查询依赖临时脚本，不能作为可复用工具使用。远端执行器源码不可得，且其 quiz 自动答题未通过验收。

## Solution

提供独立的测验命令族，通过既有雨课堂登录态直接访问官方 quiz 接口。当前调用方 Agent 读取题面并生成结构化答案；代码负责目标校验、答案校验、仅缓存保存和官方回读。正式交卷是独立操作，要求用户在下一条消息确认，确认绑定当时的测验、登录主体及已保存答案。

## User Stories

1. 作为用户，我能从课程活动中明确识别测验，避免将其当成考试。
2. 作为用户，我能只读查看指定测验的状态和已保存进度。
3. 作为用户，我能确认开始指定测验，且不会因此交卷。
4. 作为调用方 Agent，我能按题读取完整题干、选项、图片地址与填空编号，且不会得到未公布的标准答案。
5. 作为调用方 Agent，我能以结构化答案调用保存，无需接触 Cookie 或密码。
6. 作为用户，我的已有有效答案会保留；同一内容不被重复写入。
7. 作为用户，保存成功需要官方缓存回读匹配，状态仍保持正在作答。
8. 作为用户，我能看到明确的“已保存、未交卷”，保存不隐式触发正式提交。
9. 作为用户，我要求交卷时先看到测验及答题进度的确认预览，再在下一条消息确认。
10. 作为用户，确认后测验主体、题面或已保存答案变化时停止交卷，避免提交与预览不一致的内容。
11. 作为用户，交卷结果不确定时只进行只读核对，不自动重复提交。
12. 作为用户，我能只读查看官方已公布成绩、逐题得分和错题；未公布时如实报告。
13. 作为用户，群聊、缺失身份、跨用户或过期确认不得操作个人测验。
14. 作为终端使用者，我能复用插件的相同业务流程，无需额外配置内置模型。
15. 作为维护者，我能区分本地工具成功、远端执行器能力与真实平台验收。

## Implementation Decisions

- 本轮为 LangBot 专用能力，并由独立终端适配器复用；MCP 与 Agent Skill 发布树当前没有雨课堂入口，不扩展它们的命令方言。
- 新增 `yuketang quiz show|question|start|save|submit|result`；目标显式提供课程/班级与 quiz 编号。保存提供题面版本及按问题编号组织的答案 JSON。
- 沿用私聊、既有确认令牌及用户下一条确认的机制。开始、保存沿用外部写操作确认；正式交卷创建自己的独立确认，不能复用前一步确认。
- 仅处理真实 `type=4` 的 quiz，不调用考试封面、考试 token 或 examination 路由。
- 业务模块不内置模型供应商或硬编码题目答案。调用方 Agent 负责解题；只有能实际读取图片的调用方才能处理图片题，不能把返回 URL 当作已完成视觉推理。
- 首批支持选择题与填空题的结构化校验；其它题型明确报告不支持，不猜测答案格式。
- 题面与交卷修订摘要分别绑定完整目标、当前登录主体、题面，以及官方当前答案。交卷仅使用确认时已保存的完整答案。
- 持久记录写入尝试与不确定状态，成功需要官方回读。网络超时不自动重试写入；重新确认也不得绕过未核对的写入记录。已开始、已保存同值、已交卷的重入只读返回。
- 当前聊天身份的远端监听仍在运行或无法核对停止状态时，拒绝直接写测验；不宣称存在全账号排他租约。
- 题面只输出白名单字段，剔除标准答案及用户信息；模型工具结果保留完整单题结构，不能被 QQ 通用裁剪静默丢掉。
- 成绩只使用当前登录主体的官方学生成绩接口，并遵守成绩可见性。

## Testing Decisions

- 沿用本会话已约定的公共 CLI、实际服务和外部 HTTP 接缝。使用正式 HenuCliSafe 子类覆盖生产裁剪链，独立终端复用同一业务代码。
- 替换外部雨课堂/桥 HTTP 边界与时钟；不替换自有业务模块。使用合成身份、题面和答案，不把真实题目或凭据写进测试。
- 逐项先红后绿：只读取题与去除标准答案、身份类型校验、仅保存并回读、独立确认与答案修订绑定、未知写入禁止重试、成绩可见性、私聊隔离和参数全量拒绝。
- 全量测试、类型检查、两路 Standards/Spec 审查和包内文件检查在提交前完成。
- 已交卷的真实测验只做只读状态与成绩回归；本轮不开始其它测验或再次交卷。

## Out of Scope

修改朋友服务器的源码/部署；无人值守模型服务；考试 exam、课堂实时答题；主从同步；重考或重置答卷；全账号排他锁；自动交卷。

## Further Notes

官方前端与此前真实验收已确认 quiz 的开始、缓存保存、缓存回读、正式提交及学生成绩接口分别独立。真实成功的是调用方 Agent 解题与官方保存/提交链；不得把它当作朋友的自动答题执行器已修复。
