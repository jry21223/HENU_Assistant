# 常用入口文案与图书馆校区复核

## 范围

绑定、状态、课表、提醒和图书馆入口采用短句直接给结果；保留失败、未知、过期和本人确认等业务事实。只验收绑定模板并取消，不替用户提交密码、重新绑定或预约。

## 图书馆依据

2026-10-20 使用当前 QQ 验收会话对应的已保存登录态，只读请求学校 `/v4/space/pick`。凭据不写入证据，按明确会话选择用户，未借用其他账号。只保留区域公共元数据：[脱敏区域快照](evidence/library-regions-20261020.json)。

学校返回31个区域，金明20个、明伦11个；`premisesName` 明确校区，`storeyName` 明确楼层，`nameMerge` 提供层级交叉核对。第一、第二、第三自习室，以及当前列表中的东馆、西馆区域均在明伦。旧配置提及的103/104/109不在当前列表中，不据此猜测归属或沿用旧编号。

展示及工具查询共用元数据解析：校区冲突时“校区待确认”，楼层冲突时不提供楼层，不凭区域名字猜。当天余座与指定时段可用性分别表达，未知数量不写成0。入口按校区分组，避免明伦→金明→明伦重复分组。

模型工具摘要保留完整区域选项的校区、楼层和余座。仅含最多64个区域语义摘要时，模型结果预算增加至8000字符；QQ卡片仍遵守3600字节限制。面向用户的文字不展示内部区域编号，结构化工具参数保留准确ID。

## 文案

- 绑定：解释校园账号与网站账号分别绑定，直接给私聊填写模板及取消方式。
- 状态：账号保存与登录有效分开说明；上次结果未知时明确不要重复提交密码。
- 课表：保留日期、教学周和每天分组，去掉重复流程标题。
- 提醒：说明课前15分钟、连堂一次和关闭方式，不把接口受理写成实际送达。
- 图书馆：直接显示校区、区域和剩余座位，缺信息只问必要项。
- 模型系统提示词：移除旧编号归属表，使用实时 `campus/floor`，仍严格限制指定校区和写操作确认。
