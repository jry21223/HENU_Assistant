# 雨课堂课程范围解析修复

用户授权修复插件并上线。真实案例：课程 `course.name=数据结构`，班级标签 `name=010 班`，班级 ID 31921915；原 CLI 将课程名原样保存，执行器按班级标签比较而跳过。

通过公开 CLI 与现有 Storage/桥事务接缝测试：考试白名单新增接受课程名或班级标签，登录后读取真实课程列表，唯一匹配后保存班级标签；不存在、歧义、重复标签或查询失败不改配置、不推桥。移除原有字符串与清空必须在未登录/桥不可达时仍可执行。保留真实用户二次确认与先 Storage 后桥的顺序；不自动迁移或启用任何存量账号。

增加 `yuketang courses` 与 `yuketang exam list --course <课程名或班级标签>` 只读查询，使用当前用户登录态，仅 GET 课程、考试列表和封面；空列表成功与接口错误分开；不生成考试令牌、不开始考试、不读题目或提交答案。结果不含 Cookie、密码、完整原始响应或教师/学生个人资料。同名多班要求查看课程列表并明确选择班级标签；含空格标签需要引号。其他 lesson 范围语义保持现状。

更新帮助、工具提示和 README，明确考试白名单后台保存班级标签。上线采用线上现有 2.1.0 的受控补丁，保留额外 Storage/登录/预约修复，具备源码哈希比对、备份、回滚与真实只读验收。公开分支修复通过 PR/CI 合入；不发布旧 2.0.4 整包覆盖新版生产。
