# QQ 菜单与使用流程优化

确认范围：私聊菜单「我的校园／找自习室／账号与帮助」；私聊与群聊面板；绑定引导、状态、今天/明天/下一节/同步课表、自习室查询。保留生产增量功能。

- 菜单只填入自然语言，不自动提交预约或绑定；面板指令名称就是用户输入。
- 校园账号与 HENU KIT 网站账号分别说明；凭据只走既有私聊拦截和原确认流程。
- 公共引导可群聊查看，个人查询仍由现有私聊保护处理。
- 课表推送尚未实现，明确说明；不恢复其他停用功能。
- 卡片结果在前、关键详情其次、下一步最后；去除英文结构字段标题和重复当天列表，保留周次限制。
- QQ API：先读取、备份；只管理本功能 remark 标记的全局面板，分页完整读取，幂等更新，保留其他面板；菜单整体替换须备份回读。
- 测试边界已由用户确认：菜单 API、消息入口、卡片输出。红绿逐片，最终 Standards/Spec 审查；真实 QQ 客户端单独验收。

## 部署与保留线上功能

操作者入口 `ops/configure-qq-navigation.py --backup-dir <新目录>` 默认仅读取并保存预览；明确加 `--apply` 才更新。凭据通过 `QQ_APP_ID` / `QQ_CLIENT_SECRET` 进程环境传入，不写文件或日志。写前保存 `before.json`、`desired.json`，重新读取检测并发变更；写后保存 `changes.json`、`after.json` 并验证。异常保存 attention 和尽力读取的当前状态，禁止自动重试不明写入。所有面板冲突在首次写入前检查。

线上 listener 存在凭据 intake、输出脱敏和延迟回复等增量。最终 overlay 从 fresh 线上文件生成，只插入导航 hook；已有 intake 接管“绑定账号”，导航让出该入口并保留既有凭据保护。线上原提示词全部保留并附加入口映射。只替换允许清单文件；其他插件源码、环境、用户数据和 LangBot 主程序保持不变。部署前保护文件 hash、备份、真实 SDK 隔离回归；生产 runtime 重启后回读和检查，QQ 客户端另行验收。
